1. Install Dependencies

Open the command line, navigate to the project directory, and execute:

bash
Run
cd C:\Users\smart-home-control
pip install -r requirements.txt

2. Start the Program

bash
Run
python app.py

3. Login via QR Code

After startup, a QR code will be displayed in the terminal.

Open the Mi Home APP → My → Scan, and scan the QR code in the terminal.

Confirm authorization on your phone.

Open http://localhost:5678 in your browser and click "I have completed scanning".

4. Start Using

View all devices by room

Click the switch in the upper right corner of the device for one-click control

One-click execution of quick scenes at the top

You can also access the app using your computer's IP address if your phone is connected to the same Wi-Fi network.

**Automatic login will be activated next time. Valid for approximately 30 days.**
